Tradesoft KB API

REST API для доступа к базе знаний Tradesoft

Базовый URL: http://localhost:8055 | https://kb.tradesoft.corp

  • Endpoints

Механизм поиска

Поиск использует гибридную модель, комбинирующую три метода:

1. FTS (Full-Text Search)

  • SQLite FTS5 с морфологическим анализом (pymorphy3)
  • Стемминг русских слов для точного совпадения форм
  • Лексикон для исправления опечаток

2. Vector Search

  • Ollama embeddings (nomic-embed-text)
  • Typesense vector index с cosine similarity
  • Семантическое понимание запросов

3. Hybrid (по умолчанию)

  • Комбинация FTS + Vector через Reciprocal Rank Fusion (RRF)
  • Автоматическое взвешивание результатов
  • Самообучающееся ранжирование по кликам пользователей

Выбор режима

Параметр mode в /api/v1/search:

ЗначениеОписание
hybridГибридный (рекомендуется)
ftsТолько полнотекстовый
vectorТолько векторный

Коррекция запросов

Система автоматически исправляет:

  • Опечатки — замена слов с document frequency = 0 на ближайшие известные
  • Раскладку — определение и исправление неверной раскладки клавиатуры

Результат коррекции:

  • corrected_query — исправленный запрос (null если не потребовалось)
  • correction_type — тип: typo, layout, none

Детекция продукта

Если в запросе упомянут продукт («Parts.Resource», «Интеллект» и т.д.), он определяется автоматически и возвращается в поле detected_product.

Endpoints

GET /api/v1/search

Гибридный поиск по базе знаний.

Параметры

ПараметрТипОбязательныйОписание
qstringДаПоисковый запрос
modestringНетРежим: hybrid, fts, vector (по умолчанию hybrid)
topintegerНетКоличество результатов 1-50 (по умолчанию 10)
productstringНетФильтр по продукту
debugstringНетОтладочная информация: 0 или 1

Ответ

{
  "ok": true,
  "query": "как настроить эквайринг",
  "mode": "hybrid",
  "total": 5,
  "elapsed_ms": 123.4,
  "source": "full",
  "services": {"typesense": true, "ollama": true},
  "corrected_query": null,
  "correction_type": "none",
  "detected_product": "parts-resource-guide",
  "facets": {"parts-resource-guide": 3, "parts-intellect-guide": 2},
  "results": [
    {
      "rank": 1,
      "product": "parts-resource-guide",
      "product_display": "Parts.Resource",
      "page": "acquiring",
      "title": "Настройка эквайринга",
      "snippet": "...настроить эквайринг в системе...",
      "path": "https://...",
      "score": 0.95
    }
  ]
}

GET /api/v1/document

Получение содержимого страницы документа.

Параметры

ПараметрТипОбязательныйОписание
productstringДаID продукта
pagestringДаКлюч страницы
formatstringНетФормат: html (по умолчанию) или markdown
charsintegerНетМакс. символов (по умолчанию 30000)

Ответ (format=html)

{
  "ok": true,
  "product": "parts-resource-guide",
  "product_display": "Parts.Resource",
  "page": "acquiring",
  "title": "Настройка эквайринга",
  "path": "...",
  "chars": 4521,
  "truncated": false,
  "content_html": "<div class=\"page-content\">...</div>"
}

Ответ (format=markdown)

{
  "ok": true,
  "product": "parts-resource-guide",
  "product_display": "Parts.Resource",
  "page": "acquiring",
  "title": "Настройка эквайринга",
  "path": "...",
  "chars": 4521,
  "truncated": false,
  "content": "# Настройка эквайринга\n\nДля настройки..."
}

Примеры использования

Python

import requests

# Поиск
r = requests.get("http://localhost:8055/api/v1/search", params={
    "q": "как настроить эквайринг",
    "mode": "hybrid",
    "top": 5
})
data = r.json()

# Получение документа
doc = requests.get("http://localhost:8055/api/v1/document", params={
    "product": data["results"][0]["product"],
    "page": data["results"][0]["page"],
    "format": "markdown"
}).json()

# Список продуктов
products = requests.get("http://localhost:8055/api/v1/products").json()

# Статистика
stats = requests.get("http://localhost:8055/api/v1/index/stats").json()

cURL

# Поиск
curl "http://localhost:8055/api/v1/search?q=эквайринг&top=5"

# Документ в markdown
curl "http://localhost:8055/api/v1/document?product=parts-resource-guide&page=acquiring&format=markdown"

# Продукты
curl "http://localhost:8055/api/v1/products"

# Страницы продукта
curl "http://localhost:8055/api/v1/products/parts-resource-guide/pages"

# Статистика
curl "http://localhost:8055/api/v1/index/stats"

# Debug режим
curl "http://localhost:8055/api/v1/search?q=эквайринг&debug=1"

JavaScript

// Поиск
const search = await fetch("/api/v1/search?q=эквайринг&top=5").then(r => r.json());

// Документ
const doc = await fetch(`/api/v1/document?product=${search.results[0].product}&page=${search.results[0].page}`).then(r => r.json());
