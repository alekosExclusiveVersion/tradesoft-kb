### Настройки правила импорта

Импорт документов из Диадок позволяет автоматизировать создание приходных документов и заданий на разбор товара от контрагентов из системы Диадок.
По созданным в программе правилам осуществляется поиск документов (УПД, счета-фактуры, ТОРГ‑12) с их последующей загрузкой в программу.

Для создания правила, ориентированного на получение документов из системы Диадок, необходимо перейти в раздел **Склад и закупки ► Автоимпорт приходных документов **и в поле **Тип источника **выбрать вариант **Диадок**.
Правило с указанными типом источника содержит следующие настройки:
![Настройки правила импорта](images/nastrojki_pravila_importa/drex_nastrojki_pravila_importa_screen.png)

#### Настройки подключения

Блок содержит следующие настройки:

- **Активность** – позволяет установить активность каждого правила;

- **Тип источника *** – выбор типа источника для обработки входящих документов. Для импорта из Диадок необходимо выбрать вариант **Диадок**;

- **Источник *** – выбор учетной записи **Диадок **из раздела **Управление ► Справочники ► Учетные записи Диадок**, с которой будет происходить сбор входящих документов.

#### Настройки правил

Блок содержит опцию** Типы документов для импорта**, которая определяет те типы входящих документов, которые будут отбираться при обработке. Для выбора доступны:

- Счет-фактура;

- УПД;

- ТОРГ-12.

#### Настройки импорта

Блок содержит следующие опции:

- **Поставщик** – выбор **Поставщика **из справочника, по которому будут отфильтрованы входящие документы;

- **Наша фирма** – выбор **Нашей фирмы**, по которой будут отфильтрованы входящие документы;

- **Склад*** – выбор склада, который будет установлен в соответствующее поле в созданном документе;

- **Ответственный*** – выбор сотрудника из списка пользователей, созданных в разделе** Управление ► Настройки программы ► Пользователи**. Выбранный сотрудник будет являться автором документа** Приходная накладная** и/или** Задания на разбор товара**. Ответственному сотруднику на указанный в карточке пользователя email будет отправляться письмо, содержащее информацию о лишних позициях по цене и/или количеству, нераспознанных позициях, а также отчет о результатах импорта каждого файла (с указанием наименования файла лога).

- **Действие с приходной накладной** – выбор действия по созданию документа** Приходная накладная**:

- **Не создавать** – документ **Приходная накладная** не будет создан;

- **Сохранить** – документ** Приходная накладная** будет создан и сохранен в программе без проведения.

- **Действие с Заданием на разбор товара** – выбор действия по созданию **Задания на разбор товара**:

- **Не создавать** – документ** Задание на разбор товара** не будет создан;

- **Черновик** – документ** Задание на разбор товара** будет создан с состоянием документа:** Черновик**. В данном состоянии доступна возможность полного редактирования документа;

- **В очереди** – документ** Задание на разбор товара** будет создан с состоянием документа:** В очереди**. Данное состояние служит для передачи задания на склад, формируя тем самым очередь на разбор для склада/ТТ. В этом состоянии отсутствует возможность изменять документ**;**

- **В работе** – документ** Задание на разбор товара** будет создано с состоянием документа:** В работе**. Данное состояние отражает то, что товар из задания разбирается на складе. Ключевой особенностью задания в этом состоянии является возможность работы с документом одновременно нескольким пользователям;

- **Действие с лишними товарами** – действие по товарам, не найденным среди** Заказов поставщику**. Доступны значения:** добавлять в документ** и** не добавлять в документ**.

#### Обслуживание

Блок содержит опцию **Управление входящими документами **с кнопкой** Управление...**,** **при нажатии на которую открывается меню** Управление входящими документами**.
Меню содержит табличную часть со списком найденных в Диадок документов, соответствующих правилу, и позволяет вручную отметить, какие документы необходимо обработать (при помощи кнопки **Обработать**).
Таблица содержит следующие колонки:
![Настройки правила импорта](images/nastrojki_pravila_importa/drex_nastrojki_pravila_importa_screen_2.png)

- **Обработать **– отметка, которая определяет будет ли помещен указанный документ в очередь для обработки при нажатии на кнопку **Выбрать**;

- **Наша фирма **– значение из карточки контрагента-нашей фирмы, из поля **Отображать как**. Если поле не заполнено, то значение заполняется из поля **Наименование контрагента**;

- **Поставщик **– значение из карточки контрагента-поставщика из поля **Отображать как**. Если поле не заполнено, то значение заполняется из поля** Наименование контрагента**;

- **Тип документа **– тип документа из ЭДО (УПД, Счет-фактура, ТОРГ-12);

- **Номер/дата документа **в** **формате № [номер] от [дата];

- **Сумма**.

При автоимпорте входящих документов из Диадок (**Приходная накладная**, **Задание на разбор товара**) система также считывает значение GTIN из упрощённого XML для каждой позиции.
Запись считанного значения в карточку товара выполняется по следующему алгоритму:

- если карточка товара по позиции подобрана:

- поле **GTIN** в карточке пусто – система записывает считанное значение;

- поле **GTIN **заполнено и совпадает со считанным – карточка не изменяется;

- поле **GTIN **заполнено и не совпадает со считанным – карточка не изменяется, расхождение фиксируется в логе автоимпорта.

- если карточка товара не подобрана – GTIN не сохраняется.
